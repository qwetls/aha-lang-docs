# Mengapa AHA! Lang: Filosofi di Balik Desain

Setiap bahasa punya alasan mengapa ia dirancang dengan cara tertentu. AHA! Lang tidak lahir dari keinginan meniru bahasa lain, tapi dari kebutuhan akan pendekatan yang berbeda.

## if sebagai Ekspresi, Bukan Statement

Di AHA! Lang, `if` adalah ekspresi — ia menghasilkan nilai:

```rust
let status = if nilai >= 70 { "Lulus" } else { "Tidak lulus" };
print_str(status);
```

Ini bukan sekadar gaya. Ini konsistensi: jika fungsi mengembalikan ekspresi terakhir, maka `if` pun harus bisa menjadi ekspresi terakhir itu. Tidak ada jurang antara "kode yang menghitung" dan "kode yang bercabang" — semuanya ekspresi.

## Logika adalah Angka

Di AHA! Lang, hasil perbandingan dan logika adalah bilangan biasa (`Int` 0 atau 1):

```rust
let x = 5;
print((x > 3) * 100);     // 100
print((x > 3) == 1);      // 1
```

Konsekuensinya: logika bisa langsung mengalir ke aritmetika. Tidak ada casting, tidak ada konversi — semuanya `Int`. Ini membuat kode lebih pendek dan lebih langsung.

## Minimal, Bukan Minimalis

AHA! Lang hanya punya **13 kata kunci** — tidak lebih. Setiap kata kunci hadir karena benar-benar diperlukan:

- `let` untuk binding, bukan deklarasi gaya
- `fn` untuk fungsi, tanpa `def`/`func`/`function`
- `struct` untuk data terstruktur, tanpa kelas, tanpa pewarisan

Tapi minimal bukan berarti lemah. Struct punya field bertipe, fungsi punya first-class call, kontrol alur lengkap — semua tanpa menambah jumlah kata kunci.

## Kompilasi, Bukan Interpretasi

AHA! Lang dikompilasi ke kode mesin via LLVM dan dieksekusi JIT. Ini berarti:

- Kecepatan mendekati native
- Tidak ada runtime yang berat
- Bahasa ini bisa berjalan di mana LLVM bisa — dari server hingga embedded

## Tanpa Garbage Collector

AHA! Lang tidak punya GC — dan ini sengaja. GC membawa pause tak terduga dan alokasi memori yang boros. Sebagai gantinya, AHA! mengincar manajemen memori yang *deterministik* dan *tanpa kebocoran* — tapi ini masih dalam pengembangan (F5, dibekukan sementara sampai fondasi stabil).

## Bahasa yang Mendefinisikan Dirinya Sendiri

AHA! Lang tidak berusaha menjadi "Python versi cepat" atau "C yang lebih mudah." Ia punya tujuannya sendiri: bahasa yang *easy to read, powerful to wield* — dari web hingga embedded, tanpa memaksa pengembang memilih antara kecepatan dan kesederhanaan.
