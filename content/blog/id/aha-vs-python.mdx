# AHA! Lang vs Python: Dua Gaya, Satu Tujuan

Python adalah bahasa pertama paling populer di dunia — dan untuk alasan yang bagus: sederhana, ramah, ekosistem raksasa. Jadi mengapa mempertimbangkan AHA! Lang? Karena keduanya punya filosofi berbeda, dan keduanya valid untuk dipelajari.

## Kode yang Sama, Gaya Berbeda

Mari bandingkan program yang sama — menentukan kelulusan:

**Python:**

```python
nilai = 85
if nilai >= 70:
    status = "Lulus"
else:
    status = "Tidak lulus"
print(status)
```

**AHA! Lang:**

```rust
let nilai = 85;
let status = if nilai >= 70 { "Lulus" } else { "Tidak lulus" };
print_str(status);
```

Kedua program mencetak `Lulus`. Tapi perhatikan perbedaannya:

| Aspek | Python | AHA! Lang |
|-------|--------|-----------|
| `if` | Statement (menjalankan) | Ekspresi (menghasilkan nilai) |
| Boolean | `True`/`False` | `Int` `1`/`0` |
| Variabel | Deklarasi opsional gaya | `let` eksplisit |
| Eksekusi | Interpretasi | Kompilasi JIT via LLVM |

## Perbedaan Paling Menarik: Boolean

Ini perbedaan desain yang paling terasa. Di Python, `True` dan `False` adalah tipe khusus. Di AHA! Lang, hasil logika adalah bilangan biasa:

```rust
let x = 5;
print((x > 3) * 100);     // 100 — logika bisa langsung dihitung
print((x > 3) == 1);      // 1 — dan bisa dibandingkan
```

Di Python, menulis `(x > 3) * 100` akan error — `True` dikalikan angka tidak masuk akal. Di AHA! Lang, justru itulah kekuatannya: **logika mengalir ke dalam aritmetika**. Ini gaya yang lebih dekat ke C, tapi tanpa kerumitan C.

## Kecepatan Eksekusi

Python diinterpretasikan; AHA! Lang dikompilasi ke kode mesin via LLVM lalu dieksekusi JIT. Untuk program besar yang menghitung berat, perbedaan performanya signifikan — mendekati kecepatan C.

Namun jujur saja: untuk belajar konsep, kecepatan jarang jadi masalah. Kecepatan mulai terasa saat kamu membangun kompiler, simulator, atau game.

## Mana yang Harus Kamu Pelajari?

**Pilih Python jika:** kamu ingin langsung masuk ke data science, web backend, atau otomasi — dan ingin ekosistem pustaka terbesar.

**Pilih AHA! Lang jika:** kamu penasaran bagaimana bahasa bekerja dari dalam, ingin merasakan kompiler beneran, atau menyukai sintaks minimal yang "bisa dibaca seperti prosa".

**Atau pelajari keduanya!** Banyak institusi mengajarkan Python sebagai bahasa pertama dan C sebagai bahasa kedua untuk memahami mesin. AHA! Lang bisa mengisi peran keduanya sekaligus: ramah seperti Python, cepat seperti C.
