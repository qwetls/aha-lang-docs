# Bekerja dengan String

**String** adalah data teks — nama, kalimat, pesan, atau apa pun yang berbentuk huruf. Di AHA! Lang, string ditulis di antara tanda kutip ganda: `"..."

## Membuat String

```rust
let nama = "Budi";
let pesan = "Selamat datang di AHA! Lang!";
let kosong = "";
```

## Mencetak dan Menggabungkan

Untuk menggabungkan dua string, gunakan `+`:

```rust
let nama = "Budi";
let sapaan = "Halo, " + nama + "!";

print_str(sapaan); // Halo, Budi!
```

Penggabungan bekerja untuk string dengan string saja — `"umur " + 25` akan ditolak kompiler karena tipe tidak cocok (`String + Int`).

## Escape Sequence

Beberapa karakter khusus butuh cara khusus untuk ditulis di dalam string:

| Escape | Makna |
|--------|-------|
| `\n` | Baris baru |
| `\t` | Tab |
| `\\` | Garis miring `\` |
| `\"` | Tanda kutip ganda |
| `\r` | Carriage return |
| `\0` | Null |

Contoh:

```rust
print_str("Kelas A\tKelas B\nSelesai");
```

Output:

```text
Kelas A	Kelas B
Selesai
```

Bagaimana kalau mau mencetak tanda kutip di dalam string? Pakai `\"`:

```rust
print_str("Dia berkata, \"AHA!\"");
```

## Panjang String dengan `len()`

Builtin `len()` mengembalikan jumlah karakter:

```rust
print(len("hello"));  // 5
print(len(""));       // 0
print(len("AHA! Lang"));
// 9 — hitung sendiri!
```

`len()` di AHA! Lang sangat cepat: panjang string sudah disimpan sebagai bagian dari data, jadi dibaca langsung dalam O(1) — tidak perlu menghitung ulang.

## Membandingkan String

String bisa dibandingkan isinya dengan `==` dan `!=`:

```rust
let jawaban = "aha";

if jawaban == "aha" {        // hasilnya 1 (benar)
    print_str("Benar!\n");
} else {
    print_str("Salah.\n");
}
```

Perbandingan membandingkan **isi** — `"aha" == "aha aja"` adalah `0` (salah).

## String di Dalam Fungsi

String bisa dikirim ke fungsi dan dikembalikan dari fungsi:

```rust
fn seru(teks) {
    teks + "!"
}

fn sapaan_panjang(nama) {
    "Halo, " + nama + "! Semoga harimu menyenangkan."
}

print_str(seru("yuhuu"));              // yuhuu!
print_str(sapaan_panjang("Dina"));     // Halo, Dina! ...
```

Kompiler menyimpulkan tipe kembalian fungsi secara otomatis.

## Ringkasan

| Operasi | Sintaks | Contoh |
|---------|---------|--------|
| Gabung | `+` | `"a" + "b"` → `"ab"` |
| Sama dengan | `==` | `"a" == "a"` → `1` |
| Tidak sama | `!=` | `"a" != "b"` → `1` |
| Panjang | `len(s)` | `len("abc")` → `3` |
