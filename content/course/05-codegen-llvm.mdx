# Codegen dengan LLVM

Dua tahap terakhir membahas analisis: lexing, parsing, dan type checking. Sekarang tiba bagian menakjubkan: **code generation** — mengubah AST menjadi kode yang benar-benar bisa dijalankan mesin.

## Kenapa LLVM?

Menulis codegen dari nol ke kode mesin x86/ARM adalah proyek raksasa. **LLVM** (Low Level Virtual Machine) — framework compiler yang juga dipakai Clang, Rust, dan Swift — menyelesaikan sebagian besar pekerjaan itu. AHA! Lang memakai LLVM lewat binding inkwell.

Alur kerjanya:

```text
AST  →  LLVM IR (kode menengah)  →  (LLVM)  →  kode mesin asli
```

Kita hanya perlu membuat **LLVM IR** — representasi menengah yang hampir seperti assembly tapi lebih tinggi level — lalu LLVM yang menangani optimasi dan generasi kode mesin untuk arsitektur apa pun.

## Contoh: AST Menjadi IR

Ingat AST dari `2 + 3`:

```text
BinaryOp(+)
├── left: Int(2)
└── right: Int(3)
```

Codegen menghasilkan nilai LLVM untuk tiap node, lalu mengombinasikannya:

```llvm
; ilustrasi LLVM IR
%1 = alloca i64            ; alokasi slot variabel
%2 = add i64 2, 3          ; 2 + 3 → 5
store i64 %2, i64* %1      ; simpan ke variabel
```

Intinya: setiap node AST memetakan ke satu atau beberapa instruksi IR.

## Tipe Data dan Representasi

Karena AHA! Lang punya sistem tipe, codegen harus memilih representasi LLVM yang tepat:

| AHA! Type | Representasi LLVM |
|-----------|-------------------|
| `Int` | `i64` |
| `Bool` | `i1` (`true`/`false`) |
| `String` | struct `{ i8*, i64 }` — pointer + panjang |

Contoh string: `"halo"` direpresentasikan sebagai struct yang menyimpan pointer ke buffer karakter `'h','a','l','o',0` dan panjang `4`. Karena panjang disimpan, builtin `len()` bisa membacanya dalam O(1) tanpa menghitung karakter satu per satu:

```rust
let s = "halo";
print(len(s)); // 4 — dibaca dari field panjang struct
```

## Menggabungkan String

Konkatenasi `"a" + "b"` perlu buffer baru. Codegen AHA! Lang memanggil fungsi C `malloc` untuk mengalokasikan cukup ruang, `memcpy` untuk menyalin kedua bagian, lalu menulis null-terminator:

```rust
let sapaan = "halo" + " " + "dunia";
print(sapaan); // "halo dunia" — alokasi via malloc + memcpy
```

Itulah kenapa AHA! Lang men-declare fungsi eksternal C seperti `malloc`, `memcpy`, `strlen`, dan `strcmp` — semuanya tersedia di runtime sistem.

## Lingkup Variabel

Codegen juga mengelola **scope** variabel. Setiap variabel punya slot (`alloca`) dan posisi penyimpanan; ketika program keluar dari blok `if` atau loop, informasi variabel dibersihkan dengan benar — mencegah variabel "bocor" ke luar scope:

```rust
if true {
    let sementara = 5;
}
print(sementara); // ERROR: sementara tidak dikenal di sini
```

## Bagian "JIT"

AHA! Lang menggunakan LLVM dalam mode **JIT** (*Just-In-Time*): kode mesin dikompilasi saat program diminta, lalu langsung dieksekusi. Buka pelajaran terakhir untuk melihatnya: [JIT dan Mencoba AHA!](/course/06-jit-dan-coba-aha).
