# CLI Reference

Compiler AHA! adalah satu binary yang melakukan lexing, parsing, membangkitkan LLVM IR, dan mengeksekusi program Anda dengan JIT. Anda mengendalikannya sepenuhnya dari baris perintah.

## Opsi

| Opsi | Deskripsi |
|--------|-------------|
| `--file <path>` | Berkas sumber untuk dikompilasi dan dieksekusi |
| `--emit-ir <path>` | Simpan LLVM IR yang dihasilkan ke sebuah berkas |
| `--version` | Cetak versi compiler |
| `--help` | Tampilkan informasi penggunaan |

## Menjalankan Program

```bash
cargo run --release -- --file example.aha
```

Compiler menelusuri seluruh pipeline — lexing, parsing, pemeriksaan tipe, pembangkitan kode LLVM — lalu mengeksekusi hasilnya dengan JIT:

```
--- AHA! COMPILER ---
Reading file: example.aha

[1] LEXING...
[2] PARSING...
Parsing successful!

[3] CODE GENERATION...
LLVM IR generated successfully!

--- LLVM IR OUTPUT ---
; ModuleID = 'aha_module'
...
----------------------

[4] EXECUTION (JIT)...
Program executed successfully. Result: 20
```

## Mengeluarkan LLVM IR

Gunakan `--emit-ir` untuk menulis IR yang dihasilkan ke sebuah berkas — praktis untuk memeriksa persis apa yang diproduksi compiler:

```bash
cargo run --release -- --file example.aha --emit-ir out.ll
```

Berkas `out.ll` berisi LLVM IR tekstual (`; ModuleID = 'aha_module'` …) yang dieksekusi oleh JIT.

## Versi & Bantuan

```bash
cargo run --release -- --version
cargo run --release -- --help
```

## Setelah Membangun Binary Release

Setelah Anda menjalankan `cargo build --release`, compiler berada di `target/release/aha` dan dapat dipanggil langsung:

```bash
./target/release/aha --file example.aha
```

Lihat [Getting Started](/id/getting-started) untuk instruksi pembangunan.
