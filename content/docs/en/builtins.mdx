# Builtins

Every AHA! program gets a small set of standard builtins:

| Builtin | Description |
|---------|-------------|
| `print(int)` | Print an integer |
| `print_str(string)` | Print a string |
| `len(string)` | String length in O(1) |
| `abs(x)` | Absolute value |
| `min(a, b)` | Smaller of two numbers |
| `max(a, b)` | Larger of two numbers |
| `list_new()` | Create an empty `List<Int>` |
| `list_new_string()` | Create an empty `List<String>` |
| `list_push(list, elem)` | Append an element; returns the list |
| `list_get(list, index)` | Read element at index |
| `list_len(list)` | Number of elements in O(1) |
| `list_free(list)` | Free the heap buffer; returns 0 |
| `map_new()` | Create an empty `Map<Int, Int>` |
| `map_new_string_key()` | Create an empty `Map<String, Int>` |
| `map_new_string_val()` | Create an empty `Map<Int, String>` |
| `map_strings_new()` | Create an empty `Map<String, String>` |
| `map_set(m, key, val)` | Insert or overwrite; returns the map |
| `map_get(m, key)` | Read value (0 if missing) |
| `map_contains(m, key)` | Returns 1 if key exists, 0 otherwise |
| `map_remove(m, key)` | Remove key; returns the map |
| `map_len(m)` | Number of entries in O(1) |
| `map_free(m)` | Free the heap buffer; returns 0 |

## Examples

```rust
print(42);           // 42
print_str("hello");  // hello
print(len("hello")); // 5
print(abs(-7));      // 7
print(min(3, 9));    // 3
print(max(3, 9));    // 9

let xs = list_new();
list_push(xs, 10);
list_push(xs, 20);
print(list_get(xs, 1)); // 20
print(list_len(xs));    // 2
```

## Notes

- `print` takes an integer; `print_str` takes a string. `print("hi")` is a compile-time type error — strings go through `print_str`.
- `len` returns the stored length of the string struct, so it is O(1) regardless of string size.
- List builtins operate on `List<T>` handles; see [Lists](/en/lists) for the full reference.
